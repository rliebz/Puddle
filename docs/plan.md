# Plan: Puddle -> Browser -> Vercel

## Objective
Make the game playable in a browser and deploy to Vercel, while keeping changes safe and reviewable.

## Workflow rules
- Plan in repo files, not in chat
- Write a design spec, then a dev spec, then do small spikes
- Keep spikes timeboxed and reversible
- Commit small checkpoints often

## Deliverables (docs first)
- docs/repo-map.md
- docs/web-port-feasibility.md
- docs/spike-plan.md

## Build discipline
- No large refactors until feasibility is proven
- Every spike ends with a short findings note and a checkpoint commit
